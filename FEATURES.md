## 🤖 Automation

### Workflows Created

1. **update-stats.yml**
   - Updates WakaTime coding statistics
   - Runs every 6 hours
   - Manual trigger available
   - Requires: WAKATIME_API_KEY, GH_TOKEN

2. **snake-animation.yml**
   - Generates contribution snake
   - Runs daily at midnight
   - Runs on every push to main/master
   - Manual trigger available
   - No secrets required
